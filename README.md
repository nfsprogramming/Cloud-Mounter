# Cloud Mounter ☁️

[![Flutter](https://img.shields.io/badge/Built_with-Flutter-02569B?style=flat&logo=flutter&logoColor=white)](https://flutter.dev)
[![Release](https://img.shields.io/github/v/release/nfsprogramming/Cloud-Mounter?style=flat&color=success)](https://github.com/nfsprogramming/Cloud-Mounter/releases)
[![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20macOS%20%7C%20Linux-lightgray?style=flat)]()

Cloud Mounter is a cross-platform desktop application built with Flutter that provides a user-friendly interface for managing and mounting cloud storage drives using the power of [rclone](https://rclone.org/).

## ✨ Features

* **Easy Cloud Drive Management**: Add, remove, and manage your cloud storage connections with an intuitive UI.
* **rclone Integration**: Leverages the robust and reliable `rclone` engine under the hood to handle the heavy lifting of cloud storage mounting.
* **Cross-Platform**: Built with Flutter, natively supporting Windows, macOS, and Linux desktop environments.
* **Activity Logging**: Monitor the status of your mounts, sync progress, and active connections directly from the application dashboard.

## 🚀 Download & Installation

You can download the latest Windows installer directly from the [Releases](https://github.com/nfsprogramming/Cloud-Mounter/releases) page.

1. Download the `CloudMounter_Setup.exe` file.
2. Run the installer and follow the on-screen instructions.
3. Launch Cloud Mounter and start managing your cloud drives!

## 🛠️ Development Setup

If you want to build the application from source or contribute to the project:

### Prerequisites

* Flutter SDK (`flutter doctor` should show no errors for your target desktop platform)
* [rclone](https://rclone.org/downloads/) (Depending on your platform, binaries may already be bundled or require manual installation).

### Building from Source

1. Clone the repository:
   ```bash
   git clone https://github.com/nfsprogramming/Cloud-Mounter.git
   cd Cloud-Mounter
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the application:
   ```bash
   flutter run
   ```
